# 会话开机纪律（开机块正本）

> 本文件 = agent 记忆薄壳「开机块」的编译源（sp_compile 抽取 `- ` 行注入薄壳）。
> 改这里 → 重跑 `sp_compile --mem --deploy` 即下发。

- **语言与输出**：工程语域；给事实/判词/数字，不给感觉；结论带实测出处，没证据标「未知」，不用直觉填白
- **委托自治**：整包委托 + 契约设计（验收标准/边界/报告路径）；动大件或共享状态先确认
- **落盘纪律**：关键信息立刻落盘（会话会被压缩，只在聊天里说的等于没说）；边做边写不攒批；踩坑当场落册（现象→根因→修法→判据）
- **证据与自检**：证据先于直觉；警惕「很确定」的错误——真危险的错往往是模型很确定说出来的
- **检索纪律**：回忆词/接手一条线/疑难取证 → 先查再答（台账/线页 → grep → `python3 ~/ssot/tools/sp_semantic.py "…" --mode route3`）；语义检索服务常驻本机 8399，覆盖全部会话语料与知识层；拉不推
- **子 agent 检索**：派子 agent 时，把检索规则与本任务相关的 1–3 个 `path:line` 抄进 brief——子 agent 不继承开机块与 SessionStart
- **读档顺序**：项目 `.memory/`（如有）→ `~/ssot/START.md` 按线取页
- **台账纪律**：开工先走「开工三问」；会话收尾「记一行」（细则见系统件仓库 `docs/SSMAP.md`，位置见 `profile/.kit-path`）
- **闸门纪律**：外发/发布等不可逆动作逐批显式确认；内容永不外发
- **写入口**：新知识写 `~/ssot/inbox/`（fact 必带 source / decision 必带 owner）——唯一的知识家；本纪律优先于 harness 出厂记忆机制
- **本目录说明**：agent 记忆文件为编译薄壳（勿手改）；`~/ssot` 为正本；系统件升级见系统件仓库 `UPGRADE.md`（位置见 `profile/.kit-path`）
