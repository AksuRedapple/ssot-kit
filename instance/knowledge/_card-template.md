# s1 会话卡模板（吸收作业）

> 对单个会话做「读一遍 → 提炼成卡」时照此四段式；卡放 `knowledge/topics/` 或随线页归档。

```
## <sid8> ｜ <date> ｜ <线/ws>
- 主题：≤15 字
- 价值：高/中/低 ｜ 理由（≤20 字）
- 提炼：事实/机制（1-3 条）｜ 决策（带 owner）｜ 坑与纪律（如有）
- 置信：实测/推断/待核（关键事实时写）
- 可吸收：1-3 条（仅高价值写）
- 归位建议：knowledge/topics/xxx ｜ lines/xxx ｜ inbox 行 ｜ 无
```

**大文件策略**：>300KB 的语料 = 读头 150KB + 尾 50KB + `grep` 关键主题定位，不逐字读。

**判据**：每张卡要么能指向一个归位处（可执行），要么明确写「无」；不写空泛总结。
